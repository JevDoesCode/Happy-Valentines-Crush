# For my langga

Open `index.html` in a browser, or right-click it in VS Code and choose **Open with Live Server**.

```
love-site/
├── index.html          page structure (sections + SVG art)
├── css/
│   ├── base.css        colours, background, shared layout
│   ├── hero.css        "Hello langga" screen + buttons
│   ├── flowers.css     roses, vase, envelope
│   ├── player.css      mini music player
│   ├── letter.css      the paper letter
│   └── motion.css      animations, phone layout, reduced motion
├── js/
│   ├── config.js       EDIT THIS: GIF, song and letter
│   ├── effects.js      floating hearts + tap bursts
│   └── main.js         buttons, scrolling, letter rendering
└── assets/
    ├── gif/            put your GIF here
    ├── audio/          put your song here
    └── images/         favicon and any other images
```
